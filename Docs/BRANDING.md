# User-supplied branding

The wallpaper supplied in chat says **DoomOS Competitive Edition**. It is preserved as source art, not misrepresented as Balanced Gaming Edition. The second uploaded image is a 1672×941 icon *sheet*, not individual Windows .ico files.

Locally, `Branding/DoomOS-Wallpaper.jpg` is a JPEG-converted wallpaper. `Branding/DoomOS-System-Icon-Reference.png` is the sheet. Do not replace protected system binaries or signed shell icons.

Later phases will copy owned wallpaper to Windows\Web\Wallpaper\DoomOS, specify a Windows .theme or supported unattend desktop theme, and use .ico files for **shortcuts**. OEMInformation branding is optional and should not falsify ASUS as hardware manufacturer. Lock-screen policy availability depends on Windows edition.
